插件名称:Auth 网络验证插件
插件功能:注册码远程验证、有效期检查、机器码绑定、心跳保活、解绑、公告、自定义数据、客户端信息上报。
调用方式:插件放入按键精灵 plugin 目录后，使用 Plugin.Auth.xxx 调用。
机器码:机器码由多硬件信息聚合后计算 SHA256，包括 CPU、BIOS、主板、磁盘卷序列、MachineGuid、全部可见网卡 MAC、网卡名称、描述和接口类型。
安全说明:正式项目建议在后台项目 config 中配置 appSecret 或 secret。配置密钥后，服务端会校验 timestamp、nonce 和 HMAC-SHA256 签名。
命令名称:Init 初始化
命令功能:设置验证服务器、项目 appId 和项目密钥。
命令参数:参数1 serverUrl: 服务器根地址，例如 http://127.0.0.1:3000
参数2 appId: 项目标识
参数3 appSecret: 项目密钥，本地未配置可传空字符串
返回值:成功返回 1，失败返回 0。
脚本例子:
ret = Plugin.Auth.Init("http://127.0.0.1:3000", "p-1", "dev-project-secret")
命令名称:Verify 验证注册码
命令功能:提交注册码和本机机器码，首次使用时自动激活并绑定。
命令参数:参数1 licenseCode: 注册码
返回值:验证成功返回 1，失败返回 0。
脚本例子:
ret = Plugin.Auth.Verify("你的注册码")
If ret = 1 Then
    TracePrint "验证成功"
    TracePrint Plugin.Auth.GetExpireTime()
Else
    TracePrint Plugin.Auth.GetLastMessage()
End If
命令名称:Heartbeat 心跳保活
命令功能:验证成功后定时调用，用于检查过期、冻结、解绑、机器码异常。
命令参数:无
返回值:成功返回 1，失败返回 0。
命令名称:UnbindEx 解绑
命令功能:解绑注册码绑定的机器码。本机解绑可不传密码，异地解绑需要解绑密码。
命令参数:参数1 licenseCode: 注册码
参数2 unbindPassword: 解绑密码，可为空
返回值:成功返回 1，失败返回 0。
常用命令:状态与辅助接口
命令列表: GetMachineCode(): 获取本机机器码
GetVersion(): 获取插件版本
GetRemainSeconds(): 获取剩余秒数
GetExpireTime(): 获取到期时间文本
GetLicenseInfo(): 获取最近一次注册码详情 JSON
GetPlacard(): 获取公告 JSON
GetCustomData(key): 获取自定义数据 JSON
SetClientInfo(textOrJson): 上报客户端信息
ReportEvent(name, message): 上报客户端事件
Logout(): 主动下线
GetLastStatus(): 最近一次调用状态，1 成功，0 失败
GetLastCode(): 最近一次业务错误码
GetLastMessage(): 最近一次错误消息
GetLastError(): 最近一次错误消息
GetLastResponse(): 最近一次服务端原始响应
